# Ethiopian Random Quote Generator

A lightweight, responsive quote generator featuring Ethiopian proverbs and wisdom in Amharic with English meanings, plus a few international inspirational quotes.

## Run the app
1. Extract `ethiopian_random_quote_generator.zip`.
2. Open `index.html` in a modern browser.
3. Click **New Quote** to display another quote.

No installation, framework, or server is required. Google Fonts are loaded online; the app still works offline with fallback fonts.

## Files
- `index.html` — app structure
- `style.css` — responsive styling
- `script.js` — quote collection and random selection
